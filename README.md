## Status
**Demo version.** The game is playable from the main menu to the game over screen. A more polished version for my portfolio is in progress.

## How to run
1. Install **Unity 2021.3.16f1** (via Unity Hub).
2. Clone this repository and open the folder in Unity Hub (*Add project from disk*).
3. Open `Assets/Scenes/Main Menu.unity` and press **Play**.

## Controls
| Key | Action |
|---|---|
| Space | Jump (hold for a higher jump) |
| S / Down arrow | Fast fall (in the air) |
| Esc | Pause / back to menu (Game Over) |
| R | Restart (Game Over) |
